## What the game is
A reusable single-player Phaser 4 (WebGL) adventure for kids about 8-12. A new gift game = copy `src/content/starter-adventure/` and edit only that folder (title, name, characters, maps, quests, dialogue, art list). The engine (`src/engine`) never names a person. Each game has its own `gameId` (save, photo store and offline cache are named after it). Guides: `EDITING-GUIDE.md` (how to change things), `CREDITS-AND-LICENSES.md` (where every file came from; some items need a licence check before selling).

## Gotchas that cost time (full list: detail section 13)
- Phaser reserves the object field name `w` (widgets use `bw`/`bh`). Phaser 4: `setTint` + `setTintMode(FILL)`, not `setTintFill`.
- All UI text goes through `uiText()`; the pixel fonts have no accents; the small font's `0` looks like `D`.
- `art.json` is saved only through `scripts/tools/artjson.py`. Shell tools collapse `\`; write files with the Write tool.
- Animals/NPCs a follower follows must be created earlier in the list.
- Clear the browser save (`localStorage.clear()`) after the map layout changes.
